# SIMPLE PYTHON GAMES

## HANGMAN
This is a simple Hangman-style word guessing game.
The program randomly selects a word and the player guesses characters within a limited number of turns.
If the player guesses all characters correctly before the turns run out, they win; otherwise, they lose.

## WORDGUESS
This is a Python word guessing game where the player guesses letters of a randomly selected word.
The program shows the position of correct letters and allows the player to attempt guessing the full word.
The player has a limited number of turns (12) to correctly guess the word and win the game.

## WORDLE
This is a Python Wordle-style game where the player guesses a 5-letter word chosen randomly by the program.
After each guess, the program gives feedback using colors: 
🟢 correct letter and position,
🟡 correct letter wrong position,
⚫ letter not in the word.
The player has 5 attempts to guess the correct word or can type 'exit' to quit the game.
